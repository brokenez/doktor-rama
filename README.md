# Доктор Рама

Сайт и панель управления работают в одном приложении Node.js 20 или новее.

## Запуск

1. Установить зависимости командой `npm ci`.
2. В переменных окружения приложения настроить `ADMIN_PASSWORD` — действующий пароль администратора. Пароль не хранить в Git.
3. Запустить `npm start`. Порт берётся из переменной `PORT`, без неё используется 3000.

Главная страница: `/`. Панель управления: `/admin.html` или `/admin`.

## Контент

В админке доступны услуги и цены, работы с фотографиями, отзывы с оценкой и фотографией, контакты и адрес, тексты и статистика главного экрана, блок «О нас», этапы ремонта, баннер, форма заявки, логотип, меню, подвал и данные для поисковиков. На телефоне раздел выбирается в меню «Раздел сайта». Сохранение применяется к выбранному разделу; другие несохранённые разделы остаются в редакторе до выхода или перезагрузки страницы.

Имеющиеся `data.json` и фотографии не нужно заменять при обновлении. Новые поля автоматически дополняют сохранённые данные. Перед записью создаётся резервная копия `data.json.bak`, а новый файл заменяется атомарно.

Для хранения данных отдельно от Git-копии поддерживаются `DATA_FILE` — абсолютный путь к JSON-файлу и `UPLOADS_DIR` — абсолютный путь к каталогу фотографий. Каталоги должны быть доступны процессу Node.js для записи. При первом запуске с новым `DATA_FILE` приложение читает прежний `data.json` из проекта; после первого сохранения записывает полный контент в `DATA_FILE`.

## Обновление на хостинге

Перед обновлением сохранить действующий JSON-файл с контентом и каталог загруженных фотографий. После получения изменений из GitHub выполнить `npm ci` и перезапустить приложение Node.js. Веб-сервер домена должен направлять запросы `/`, `/admin.html`, `/api/`, `/uploads/` и публичные JS-файлы в это приложение. Одно обновление файлов GitHub не подтверждает перезапуск процесса или правильность маршрутизации домена.

## Проверка

`npm test` проверяет главную страницу и её файлы, вход в админку, сохранение цен и контактов, совместимость старых данных, загрузку изображений и сохранение после перезапуска. Проверки используют временные данные и не отправляют настоящих заявок.
